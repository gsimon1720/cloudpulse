\# CloudPulse — Cloud Infrastructure Monitoring Platform



CloudPulse is a cloud engineering portfolio project designed to monitor server health, resource utilization, and application availability through a centralized dashboard.



\## Project Goals



\- Collect CPU, memory, disk, and network metrics.

\- Monitor server and application availability.

\- Display real-time and historical metrics.

\- Detect abnormal resource usage and generate alerts.

\- Containerize the application with Docker.

\- Deploy the platform to AWS.

\- Automate testing and deployment with GitHub Actions.

\- Apply cloud security and monitoring best practices.



\## Planned Technology Stack



\- Frontend: React

\- Backend: Node.js and Express

\- Database: PostgreSQL

\- Monitoring: Node.js monitoring agent and AWS CloudWatch integration

\- Containers: Docker and Docker Compose

\- Cloud: AWS

\- CI/CD: GitHub Actions

\- Version Control: Git and GitHub
